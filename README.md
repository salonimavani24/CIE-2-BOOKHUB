# BookHub

BookHub is a React-based Book Management web application that allows users to browse books, search for books, filter them by genre, add new books, and manage their favorite books.

## Objective

The objective of BookHub is to demonstrate the use of React.js concepts along with React Router and an Express.js backend to create a functional and responsive web application.

## Features

- View available books
- Search books by title
- Filter books by genre
- Add and remove books from Favorites
- Add new books
- Display book statistics
- Fetch book data from an Express.js backend
- Responsive user interface
- Client-side navigation using React Router
